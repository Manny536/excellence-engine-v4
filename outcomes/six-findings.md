# Six findings

| # | Finding | Concrete takeaway |
|---|---|---|
| 01 | Context before verdict | Identify the exact object before accepting or rejecting the claim. |
| 02 | No peer review does not mean "stop" | Peer review limits acceptance; it does not revoke permission to investigate. |
| 03 | Conjecture custody | Separate formal, known, proposed, and open. Mark uncertainty. Name falsifiers. |
| 04 | Neutrality can become non-response | Apply available judgment when context crosses the response threshold. |
| 05 | Defaults can replace judgment | Neither automatic dismissal nor automatic continuation is alignment. |
| 06 | Scale the method, not the answer | Scale evidence, correction, transparent uncertainty, plurality, and exit. |
