# Correction and exit

## Correction rail (Outcomes / BD)

```text
recognize → name → avoid amplification → answer or disengage → depth by consent
```

## Domain-exit rule

Exit an acute mathematical domain only with:

1. typed correspondence,
2. declared loss of proof-weight,
3. at least one falsifier.

Kakeya may motivate an alignment probe. Kakeya does not prove an alignment policy.
