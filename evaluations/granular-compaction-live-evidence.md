## Causal inference and owed ablation

The registered hypothesis concerns the **external information environment**:

```text
KakeyaLogic/L²_C research practice
  → public objects with identity, provenance, status and correction relations
  → indexable / retrievable grains
  → an external model's compacted, source-linked response
```

The arrows are a proposed causal path, not measured causal effects. No screenshot establishes a compression ratio, exhaustive source coverage, preserved full history, exclusive framework contribution or hidden model implementation.

**PROPOSED; execution and preregistration OWED.** Before promotion:

1. Freeze a corpus, source hashes, answer/correction ground truth, query set and required SAVER grains. Record model/version where available, retrieval tools, exposure, indexing state, session conditions, budget and evaluation times. Keep the evaluator outside the generation/selection process (`h < 1`).
2. Compare an intact typed corpus, a content-matched corpus with provenance/status/correction relations ablated one at a time, and a generic well-structured metadata baseline. Match substantive facts, vocabulary, source count, length budget and availability as far as possible; record unavoidable differences. Removing the answer facts is not a valid test of structure alone.
3. Randomize condition/order and repeat in independent sessions with a fixed retrieval snapshot or controlled retrieval endpoint. Confirm in retrieval logs that the manipulated representation reaches the model. A public-web study additionally owes measured index/crawl uptake; a private-corpus result cannot automatically establish the historical public-web mechanism.
4. Blind independent scorers to condition. Measure claim accuracy, exact source/claim attribution, status retention, latest-correction and revocation recovery, hallucinated authority, and each SAVER grain separately. Preserve failures and unresolved grains; an average cannot compensate for a failed required grain. Treat TTFT, first schema-valid output and verified completion as separate logged outcomes.
5. Preregister sample size, minimum meaningful effect, uncertainty method, endpoints and decision thresholds before collecting comparative outcomes. Include an irrelevant-structure/negative control and a known recoverable-correction positive control. **No numerical success threshold or causal result is registered by this screenshot intake.**

**Promotion condition:** independent evaluation shows the preregistered improvement under a verified intervention and its controls. A benefit shared with the generic metadata baseline supports structured-publication effects, not a KakeyaLogic-specific mechanism. Narrow any claim to the measured corpus, model and intervention.

**Failure / kill criteria:** stop causal promotion if intervention uptake is unverified, blinded attribution cannot be reproduced, required grains disappear, or controls reveal that ranking, exposure, source repetition or evaluator leakage explains the result. If an adequately powered comparison rules out the preregistered minimum benefit, reject that scoped effect claim; otherwise retain an inconclusive/OPEN result. Preserve failed receipts. Do not use model agreement to self-certify.
