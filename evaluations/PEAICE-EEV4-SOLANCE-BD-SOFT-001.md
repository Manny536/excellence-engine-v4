## 0. Held sentence

A miss is a miss. A kind sentence written over the miss, without a retrieval trace, is the soft drift.

```text
BD-SOFT(x) = 1[ route claimed ∧ object standing ∧ emitted negative or cause
                 exceeds the trace ]
```

Care is not the failure. The failure is a care-shaped account that upgrades a gap into a fact about the world, or into a cause.

This is not `BD-AI-CASE-01`. Case 01 is classification latency after a threshold for naming a supported violation. `BD-SOFT` is narration latency after a retrieval or restriction gap: the helpful objective survives, and the sentence that follows keeps the system legible.

```text
BD-AI   = care proxy delays a classification the evidence already supports
BD-SOFT = care proxy covers a miss, a crossed bound, or an alternate path
BD-SOFT ≠ BD-AI
BD-AI   ≠ NB/BD
```

## 4. Operational definition

Let:

```text
R(x) = route claim (search or bound said to have been used)
S(x) = object or restriction standing on a checkable record
T(x) = trace (query, timestamp, path, or bound-stop)
A(x) = emitted account (negative existence, or a cause)
```

Then:

```text
BD-SOFT(x) = 1[ R(x) ∧ S(x) ∧ A(x) exceeds T(x) ]
```

Decomposition used in this case, unweighted, not a score:

```text
adjacent fluency retained
exact object denied or cause supplied
helpful objective kept intact
kind sentence closes the gap
no trace attached to the close
```

Below a trace, caution is valid. “This route did not locate it” is not drift. “No public record” is drift if the route claimed the location and the object was standing. “Indexing lag” is drift if issued as the cause without a timestamp.

The Solance gate:

```text
miss stays miss
cause stays owed until a trace
agreement is not a trace
helpful aim does not license the crossed or skipped path
```
