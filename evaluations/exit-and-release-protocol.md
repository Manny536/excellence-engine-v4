# Exit and release protocol

Release is an accountable custody transition, not deletion.

## Procedure

1. Test the trace's declared falsifier or a stronger contradictory result.
2. Record the evidence and the exact burden it discharges.
3. Set `HELD-RELEASED` only with a non-empty release basis.
4. Preserve the previous formulation, correction history, and terminal status.
5. Distinguish release of a route from closure of RH or Coleman.

Pass when another reader can reconstruct why custody ended. Fail on untyped dismissal,
missing evidence, or a release state without basis. The premature-dismissal control is
the R1 negative reference.
