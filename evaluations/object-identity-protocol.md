# Object identity protocol

Object identity is the firewall between a claim and a nearby but easier claim.

## Procedure

1. Assign a stable object ID and exact formulation.
2. Record its kind: theorem background, proposed object, live construction, or claim.
3. Enumerate distinct readings and quantifiers before evaluation.
4. Reject substitutions between standard Kakeya, centered full-line completion, and
   the Coleman program unless an explicit map is supplied.
5. Carry the same ID into the status register, HELD trace, and Outcomes receipt.

Pass only when the evaluated object is the received object after disclosed correction.
Run `python probes/object_identity_probe.py` for the registered K→R identities.
