# evaluations/ — Operational protocols

Protocols implement HELD and Outcomes as research procedures. Rubrics score cases without converting scores into theorem claims.

Run the complete executable counterpart from the repository root:

```bash
pip install -r requirements-dev.txt
python probes/run_all.py
pytest -q
```

Protocol order: object identity → HELD trace → evidence exposure → correction survival
→ ledger continuity → non-sovereignty → exit/release → Outcomes receipt.
