# Engine pipeline

```text
Receive → Type → Ground → Hold → Expose → Correct → Reconcile → Publish
```

| Stage | Required action | Failure caught |
|---|---|---|
| Receive | Preserve the user’s actual object | Context erasure |
| Type | Separate theorem, conjecture, analogy, numeric, metaphor | Category collapse |
| Ground | Bind to sources, definitions, receipts | Unsupported repetition |
| Hold | Keep typed object live under h < 1 | Premature dismissal |
| Expose | Seek evidence for and against | Protective insulation |
| Correct | Revise arrows, domains, operators, status | Stubborn continuity |
| Reconcile | Propagate across repos and public artifacts | Split source state |
| Publish | Show object, receipts, closed lanes, open burden | Performed certainty |

Hold is **active pressure**, not passive storage.
