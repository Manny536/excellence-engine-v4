# Contributing — Excellence Engine V4

## Claim discipline

- Never promote OPEN mathematical targets by citation or model agreement alone.
- Never write `K→R` as `Kakeya ⇒ RH`.
- Never use `HELD` as a synonym for true / proven.
- Preserve CLOSED-NEGATIVE lanes unless new structure is supplied.
- Keep `h < 1` visible on every evaluator.

## Workflow

1. Open a branch from `main`.
2. Update registers (`registry/`, `STATUS.md`) when claim status changes.
3. Run probes/tests when touching schemas or integrity pins.
4. Cross-link sibling labs (KakeyaLogic, Claude V6) without relocating controlling artifacts.

## Model readings

Grok, Claude, and Solance (GPT) readings go under `outcomes/readings/` or `registry/model-readings.md` with pole tags. Polarized by design.
